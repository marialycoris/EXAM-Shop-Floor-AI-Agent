# SOP - Edge Banding

## Purpose

Procedure for processing panels that require edge banding.

## Operator Instructions

1. Verify the panel code against the production record.
2. Confirm that the panel requires edge banding.
3. Confirm that the panel is at the Edge Banding workstation.
4. Follow the approved workstation operating procedure.
5. If the physical panel label does not match the production record, stop processing and contact a supervisor.

## Safety

Follow the approved safety procedures for the workstation.

## Machine Parameters

This prototype does not provide machine speeds, feed rates, temperatures, or other machine-specific settings.

If a machine parameter is required but is not provided in the approved SOP, contact a supervisor.
